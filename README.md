## Запуск

Используйте Python 3.11. В PowerShell из корня репозитория выполните

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt jupyterlab
.\.venv\Scripts\python.exe -m jupyterlab
```

В JupyterLab откройте нужный ноутбук и запустите все ячейки по порядку.
Графики и таблицы сохранены в ноутбуках. Для повторного запуска задания 4
нужно подключение к Kaggle для загрузки Dry Bean.

В задании 2 повторы представлены точными целочисленными весами, а тестовое
разбиение выполняется по исходным точкам. В задании 4 PCA для `df_256v`
обучается на всех 655 360 точках. Нелинейные проекции по умолчанию строятся
на стратифицированной подвыборке из 12 000 точек. Для расчёта на полном наборе
установите `$env:DF256V_EMBEDDING_SIZE = '655360'` перед запуском JupyterLab.
